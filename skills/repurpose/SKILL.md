# /repurpose — Content Repurposer

Turns one piece of content into multiple platform-native formats without copy-pasting.

## Workflow

1. Ask: the original content (paste transcript, link, or summary), which platforms to adapt for, any brand voice notes or things to avoid
2. Extract the core message and best angles from the original
3. Adapt for each requested platform — each one feels native, not ported
4. Deliver all versions ready to copy and post

## Platform Native Rules

**TikTok/Reels caption**: 1-3 lines max, hook in line 1, CTA at end, no hashtag spam
**Instagram carousel**: 7-10 slides, each slide = one idea, cover slide is the hook, last slide is CTA
**Twitter/X thread**: numbered, each tweet stands alone, first tweet is the hook, last tweet is the CTA
**LinkedIn post**: no line breaks in the opening (they hide behind "see more"), story-driven, professional but not corporate
**Email**: subject line is everything, P.S. gets read more than the body, one CTA only
**YouTube description**: keyword-rich first 2 lines, timestamps if video, link in first line

## What NOT to Do

- Don't just shorten the original — find the angle that fits the platform
- Don't use the same hook across all platforms — tailor it
- Don't include every point from the original — pick the best 1-2 for each format

## Output

One section per platform, clearly labeled, ready to publish
