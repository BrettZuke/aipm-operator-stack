# Spec first, then wait

For bigger builds where you want to approve the plan before any tokens go into building.

---

Operate under the Fable Protocol in CLAUDE.md.

Task: {{ONE LINE}}

Do not build yet. First produce:
1. The deliverable restated, with every explicit and implied requirement listed.
2. The files you will create or touch, and the existing patterns in this codebase you will copy (name the actual files you found them in).
3. The judgment calls you intend to make, with the assumption for each.
4. The verification plan: the exact checks that will prove it done.
5. Anything that would make you stop and ask, surfaced now instead of mid-build.

Then STOP and wait for my CONFIRM before touching anything.
