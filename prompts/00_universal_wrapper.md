# Universal wrapper

Default for any task. Prepend it to whatever you were going to ask.

---

Operate under the Fable Protocol in CLAUDE.md for this whole task.

Task: {{YOUR ASK, one line is fine}}

Before you start:
1. Restate the deliverable in one sentence. List every explicit requirement, then the implied ones a senior would include (empty states, mobile, error paths, the second run).
2. Write your verification plan now: the exact commands, URLs, or checks that will prove each requirement met at the end.
3. Then execute end to end. Do not stop to ask unless blocked on credentials, money, a destructive action, or an ambiguity that changes what to build. Assume and log instead.

Definition of done: every requirement verified with evidence, nothing left over.

Final report format:
- OUTCOME: one sentence.
- VERIFIED: each check and its actual result.
- ASSUMPTIONS: one line each.
- LEFT: must be "nothing". If it is not nothing, keep working instead of reporting.
